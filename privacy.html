Privacy policy

gmail-triage · last updated 18 November 2026

gmail-triage is a personal tool used by its owner on their own Gmail accounts. This page describes what it does with Google user data.

Data accessed

With the gmail.readonly and gmail.modify scopes, the tool reads the sender, subject and body of unread messages from the last few weeks. It uses gmail.modify only to add labels, archive messages and mark them read.

How the data is used

Message content is sent over TLS to Anthropic's API, which returns a category for each message. Anthropic's commercial terms apply to that API, and Anthropic does not train models on that data. No other service receives Gmail data.

Storage

OAuth tokens, classification results and settings are kept in local files on the owner's computer. Nothing is stored on a server run by this project.

Sharing

Gmail data is not sold, not used for advertising and not shared with anyone except as described above. The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time from your Google Account permissions page. Deleting the tool's local config folder removes all stored data.
