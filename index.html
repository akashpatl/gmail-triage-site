gmail-triage

A personal command-line tool for sorting Gmail.

gmail-triage runs on its owner's own computer. It reads unread messages in the owner's Gmail accounts, asks Anthropic's Claude model which category each one belongs to, then applies a Gmail label and archives low-priority mail.

It is used by one person on their own mailboxes. It is not offered to the public and there is nothing to sign up for.

Google permissions

  • gmail.readonly to read unread messages for classification.
  • gmail.modify to add labels, archive and mark messages read.

The tool never asks for permission to send mail and has no way to send it.
